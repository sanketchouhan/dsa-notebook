Arrays

Patterns and techniques for working with arrays: two-pointers, sliding windows, in-place transforms, and index mapping tricks.

💡 The Arrays Mental Model

  • Two-Pointers: Use slow/fast or left/right pointers to collapse duplicates, partition arrays, or find pairs in linear time.
  • Sliding Window: Maintain a variable-sized window over the array for subarray sums, maxima, and minimal-length problems.
  • In-Place Transforms: Overwrite existing entries with compacted results to achieve $O(1)$ extra space when allowed.
  • Index Mapping: Use index arithmetic and modular mappings for cyclic shifts and bucketed frequency problems.

1. Remove Duplicates from Sorted Array (LeetCode #26)

Easy

Given an integer array nums sorted in non-decreasing order, remove the duplicates in-place such that each unique element appears only once. Return the number of unique elements k, with the first k elements of nums holding the final result.

The "Aha!" Moment (Two-Pointer Slow/Fast Pattern):
Since the array is already sorted, duplicate values are guaranteed to sit next to each other. Use a slow write pointer (writeIndex) and a fast read pointer (readIndex). The fast pointer scans every number; whenever it encounters a value distinct from its predecessor, overwrite nums[writeIndex] with that unique value and increment the write boundary. This achieves an optimal $O(N)$ runtime with $O(1)$ extra space. 
/**
 * @param {number[]} nums
 * @return {number}
 */
var removeDuplicates = function(nums) {
    if (nums.length === 0) return 0;

    let writeIndex = 1;

    for (let readIndex = 1; readIndex < nums.length; readIndex++) {
        // Compare with the previously inspected element
        if (nums[readIndex] !== nums[readIndex - 1]) {
            nums[writeIndex] = nums[readIndex];
            writeIndex++;
        }
    }

    return writeIndex;
};

2. Remove Element (LeetCode #27)

Easy

Given an integer array nums and an integer val, remove all occurrences of val in nums in-place. The order of the elements may be changed. Return the number of elements in nums which are not equal to val.

The "Aha!" Moment (Fast/Slow Filter In-Place):
Use a read pointer to scan the array and a write pointer to define the boundary of valid elements. As readIndex steps through the array, ignore any element equal to val. Whenever a valid element (!== val) is encountered, copy it to nums[writeIndex] and advance writeIndex. This filters the array in a single pass in $O(N)$ time and $O(1)$ extra space. 
/**
 * @param {number[]} nums
 * @param {number} val
 * @return {number}
 */
var removeElement = function(nums, val) {
    if (nums.length === 0) return 0;
    
    let writeIndex = 0;

    for (let readIndex = 0; readIndex < nums.length; readIndex++) {
        // Only keep elements that do not match the target value
        if (nums[readIndex] !== val) {
            nums[writeIndex] = nums[readIndex];
            writeIndex++;
        }
    }

    return writeIndex;
};

3. Reverse String (LeetCode #344)

Easy

Write a function that reverses a string. The input string is given as an array of characters s. You must do this by modifying the input array in-place with O(1) extra memory.

The "Aha!" Moment (Opposite-Direction Two Pointers):
Place one pointer at the start (start = 0) and another at the end (end = s.length - 1). Swap the elements at these pointers, then increment start and decrement end toward each other. The process terminates when the pointers meet in the middle, achieving the reversal in $O(N)$ time and strictly $O(1)$ auxiliary space. 
/**
 * @param {character[]} s
 * @return {void} Do not return anything, modify s in-place instead.
 */
var reverseString = function(s) {
    let start = 0;
    let end = s.length - 1;

    // Swap elements from the outside in until pointers meet in the center
    while (start < end) {
        const temp = s[start];
        s[start] = s[end];
        s[end] = temp;

        start++;
        end--;
    }
};

4. Best Time to Buy and Sell Stock (LeetCode #121)

Easy

You are given an array prices where prices[i] is the price of a given stock on the i-th day. You want to maximize your profit by choosing a single day to buy one stock and choosing a different day in the future to sell that stock. Return the maximum profit you can achieve from this transaction. If you cannot achieve any profit, return 0.

The "Aha!" Moment (Reverse Traversal / Running Peak):
Instead of scanning forward and tracking the minimum buy price, you can scan backward from right to left while tracking the **maximum future selling price** (maxPrice). For every day, the best profit you could make selling in the future is maxPrice - prices[currIndex]. This evaluates all optimal sell days in a single linear pass in $O(N)$ time and $O(1)$ space. 
/**
 * @param {number[]} prices
 * @return {number}
 */
var maxProfit = function(prices) {
    let length = prices.length;
    let maxPrice = prices[length - 1];
    let maxProfit = 0;

    // Scan backwards from the rightmost element to maintain the running maximum future sell price
    for (let currIndex = length - 1; currIndex >= 0; currIndex--) {
        maxProfit = Math.max(maxProfit, maxPrice - prices[currIndex]);
        maxPrice = Math.max(maxPrice, prices[currIndex]);
    }

    return maxProfit;
};
